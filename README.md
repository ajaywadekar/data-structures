# Data Structures (102040304) - Course Website

Static course site for B.Tech (Computer Science and Design), Semester III, CVM University.
It is one self-contained file (`index.html`), so no build step is needed.

## Publish on GitHub Pages
1. Create a new public repository, for example `data-structures`.
2. Upload `index.html` and `README.md` to the repository root (Add file > Upload files).
3. Open Settings > Pages. Under "Build and deployment", choose Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.
